My Portfolio

A personal portfolio website built to showcase my technical skills, projects, and background as a software developer.

Overview

This website serves as a central place to view my work, explore the technologies I use, and learn more about my development experience.

Built With

* HTML5
* CSS3
* JavaScript

Features

* Personal introduction and about section
* Technical skills
* Project showcase
* Contact and social links
* Responsive design

Getting Started

To run the project locally:

1. Clone the repository:

git clone https://github.com/Amazingayo/my-portfolio.git

2. Open the project folder:

cd my-portfolio

3. Open index.html in your browser.
